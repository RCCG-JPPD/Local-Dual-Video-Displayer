📺 RCCG Display Controller — Help

Drive several screens at once: play a local video, a YouTube link, a web page, or a clock — all from one control panel.

Getting started (first launch)

  1. 1 When the app opens you'll see the Display Configuration screen listing every connected screen.
  2. 2 Not sure which screen is which? Click 🔦 Identify screens — a big number flashes on each physical screen.
  3. 3 For each screen, pick a role: Video, YouTube, Web Page, or Clock. Leave the screen you're working on as Unassigned.
  4. 4 Click Confirm & Continue. The control panel opens on your main screen and the content windows open on the screens you chose.

💡 You can assign Video (or any role) to several screens to mirror the same content. Your choice is remembered next time.

Playing a local video

  • In the control panel's Local Video section, click + Add Video… and choose one or more files.
  • Use Play/Pause, Previous/Next, Stop, the scrub bar, and Master Volume.
  • The video plays on every screen set to Video. Audio comes from the first Video screen; the rest are muted to avoid echo.

YouTube & Web pages

  • YouTube: paste a link (or video ID) in the YouTube box and press Enter or the button — it plays on every YouTube screen.
  • Web Page: type an address (e.g. example.com) in the Web box and press Enter — it loads on every Web screen.
  • You can prepare content before a screen is assigned to it — it's saved and appears as soon as you assign one via Reconfigure Displays.
  • Each section has a 🧹 Clear button, and the sidebar's 🧹 Clear All Content resets every screen to its idle state at once.

📽️ Presentations (PowerPoint / PDF)

  • In the Presentation section, click + Add… and pick a .pptx, .ppt, .odp, .pdf, or a set of slide images.
  • PowerPoint decks keep their animations and slide transitions. Next plays the next animation step first — exactly like PowerPoint — then advances with the slide's own transition.
  • This needs a free LibreOffice install (libreoffice.org) — the same one used to convert the deck. Without it, export your deck to PDF (slides then show statically).
  • Navigate with Previous / Next in the controller, or from your phone via Remote Mode (including jump-to-slide and blanking the screen).

Handy controls

  • Reconfigure Displays — re-open the screen picker any time to change roles.
  • Identify Screens — flash the screen numbers again.
  • Esc on any fullscreen content window closes just that screen (useful when testing on a single screen).
  • Closing the control panel quits the whole app and closes every screen.

📱 Remote Control (phone or any browser)

multi-displayer.web.app

Drive slides, the slideshow, and video playback from your phone — nothing to install. Both the computer and the phone need internet access.

  1. 1 In the control panel, open the 📱 Remote tab and click 📡 Enable Remote Mode.
  2. 2 A QR code and a 6-character session code appear. Scan that QR code with the phone's camera — it joins instantly, code included. Or scan the QR on the right (or open multi-displayer.web.app) and type the code.
  3. 3 When the phone joins, the panel shows “✓ 1 device connected”. Several devices can join with the same code.
  4. 4 The phone is a full remote: Slides (previous / next / blank / jump to a slide number), Slideshow (previous / next / play-pause), Video (pick any playlist entry, play-pause, seek, volume, stop), YouTube (send a link, play / pause / mute, volume), Web Page (open an address, back / forward / reload), and Spreadsheet (switch sheets). It shows live status — current slide, video title and time — and only shows sections that have a screen assigned.

💡 Your code lasts the whole run of the app. Changing displays or toggling Remote Mode off and on keeps the same code, and already-paired phones reconnect automatically. A new code is only issued after the app is closed and reopened.

  • ⚠️ Anyone with the code can control the presentation while Remote Mode is on — keep it private and turn Remote Mode off when you're done.
  • The session is cleaned up automatically if the app quits or loses its connection.
  • The phone remembers the last code it used, so reconnecting later is one tap.
  • Codes never contain the letters I, L, O, or U — if you think you see one, it's a 1 or a 0 (typing those works too).

Notes

  • Some websites refuse to be embedded and may not load on a Web screen.
  • YouTube videos that disable embedding won't play.
  • Remote Control needs an internet connection; everything else works fully offline.
