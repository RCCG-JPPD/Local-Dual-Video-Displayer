📺 RCCG Display Controller — Help

Drive several screens at once: play a local video, a YouTube link, a web page, or a clock — all from one control panel.

Getting started (first launch)

  1. 1 When the app opens you'll see the Display Configuration screen listing every connected screen.
  2. 2 Not sure which screen is which? Click 🔦 Identify screens — a big number flashes on each physical screen.
  3. 3 For each screen, pick a role: Video, YouTube, Web Page, or Clock. Leave the screen you're working on as Unassigned.
  4. 4 Click Confirm & Continue. The control panel opens on your main screen and the content windows open on the screens you chose.

💡 You can assign Video (or any role) to several screens to mirror the same content. Your choice is remembered next time.

Playing a local video

  • In the control panel's Local Video section, click + Add Video… and choose one or more files.
  • Use Play/Pause, Previous/Next, Stop, the scrub bar, and Master Volume.
  • The video plays on every screen set to Video. Audio comes from the first Video screen; the rest are muted to avoid echo.

YouTube & Web pages

  • YouTube: paste a link (or video ID) in the YouTube box and press Enter or the button — it plays on every YouTube screen.
  • Web Page: type an address (e.g. example.com) in the Web box and press Enter — it loads on every Web screen.
  • A section is greyed out if no screen is assigned to it — use Reconfigure Displays to add one.

Handy controls

  • Reconfigure Displays — re-open the screen picker any time to change roles.
  • Identify Screens — flash the screen numbers again.
  • Esc on any fullscreen content window closes just that screen (useful when testing on a single screen).
  • Closing the control panel quits the whole app and closes every screen.

Notes

  • Some websites refuse to be embedded and may not load on a Web screen.
  • YouTube videos that disable embedding won't play.
